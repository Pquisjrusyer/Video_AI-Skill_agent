# Brand assets — Kreizi Beauty

> Folder hiện **trống**. Các file dưới đây do **người dùng cung cấp** (lấy từ brand / designer) — Claude KHÔNG tự vẽ, tự gen hay đoán logo, badge, font, mã màu. Thiếu file nào thì `/edit` báo thiếu và dừng phần dùng file đó.

## File `/edit` (Remotion) cần

| Loại | File cần thả vào đây | Ghi chú |
|---|---|---|
| Logo | `logo-kreizi.svg` (hoặc `.png` nền trong suốt), bản sáng + bản tối nếu có | Dùng cho end card / packshot |
| Badge chứng nhận chính thức | `badge-made-in-usa`, `badge-vegan`, `badge-leaping-bunny-cruelty-free`, `badge-halal`, `badge-kosher` (`.svg`/`.png` trong suốt) | Chỉ dùng file badge chính thức của đơn vị cấp — không tự vẽ lại |
| Font | File font (`.ttf`/`.otf`/`.woff2`) + tên font heading / body | Ghi tên font vào bảng dưới |
| Palette | Mã hex màu brand | Ghi vào bảng dưới |
