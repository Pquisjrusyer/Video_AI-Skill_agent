# Audio & Voice — Remotion

## Limitation reminder (do not get this wrong)

Remotion does NOT generate speech — it is not TTS. It only imports an existing audio file and mixes/syncs it by frame. The voiceover must exist FIRST: Voiceover video → ElevenLabs VO generated by Claude at `/assets` 4D, saved in `outputs/audio/`; UGC → the TopView TTS audio inside each take (no separate VO). Music + SFX are generated/chosen by the user from the 4D prompts, also in `outputs/audio/`. At `/edit` copy `outputs/audio/` into the temp project's `public/audio/`.

---

## 1. Background music

Copy the music file (user-generated/chosen at 4D, licensed for ads) from `outputs/audio/` to `public/audio/`, keeping the raw naming convention — e.g. `public/audio/2026-06-LAUNCH_music_v1.mp3`.

```tsx
import { Audio, interpolate, staticFile, useCurrentFrame, useVideoConfig } from 'remotion';

export const BackgroundMusic: React.FC = () => {
  const frame = useCurrentFrame();
  const { durationInFrames, fps } = useVideoConfig();
  const fadeFrames = fps; // 1s fade

  const volume = interpolate(
    frame,
    [0, fadeFrames, durationInFrames - fadeFrames, durationInFrames],
    [0, 0.5, 0.5, 0],
    { extrapolateLeft: 'clamp', extrapolateRight: 'clamp' }
  );

  return <Audio src={staticFile('audio/2026-06-LAUNCH_music_v1.mp3')} volume={volume} />;
};
```

Place this component OUTSIDE the `TransitionSeries` in `Assembly.tsx` (in parallel, not inside any specific Sequence) so it runs throughout the entire video and is not cut per scene.

If the music track is shorter than the video: use the `loop` prop on `<Audio loop src={...} />`. If it is longer: use `trimAfter={durationInFrames}`.

## 2. Voiceover

### Step 1 — have the audio file first

The voiceover comes only from a TTS provider per `VO_TOOL` (ElevenLabs connector, or `_tools/gen-voice.py`: ElevenLabs API / Gemini TTS / Cloudflare / OpenAI) (`/assets` 4D, `outputs/audio/`; UGC uses the dialogue audio inside each take — Google Flow / TopView). Copy it to `public/audio/` with its raw name `[campaign-code]_vo-[scene-id]_v[n].mp3` — e.g. `public/audio/2026-06-LAUNCH_vo-S01_v1.mp3`.

### Step 2 — set the scene's duration from the audio (do not hardcode)

Common problem: the scene is hardcoded to 90 frames (3s) but the voice takes 4.2s to finish → it gets cut off. The right way: measure the audio duration FIRST, then set the Composition's `durationInFrames` from it using `calculateMetadata`.

```tsx
import { Composition, getAudioDurationInSeconds } from 'remotion';
import { staticFile } from 'remotion';

<Composition
  id="SceneWithVoice"
  component={SceneWithVoice}
  fps={30}
  width={1080}
  height={1920}
  durationInFrames={150} // default value, will be overridden below
  calculateMetadata={async () => {
    const audioSrc = staticFile('audio/2026-06-LAUNCH_vo-S01_v1.mp3');
    const durationInSeconds = await getAudioDurationInSeconds(audioSrc);
    const paddingSeconds = 0.5; // breathing room at the end of the scene before the cut/transition
    return {
      durationInFrames: Math.ceil((durationInSeconds + paddingSeconds) * 30),
    };
  }}
/>
```

Apply this approach to EVERY scene with voiceover in the storyboard — do not use a fixed 90/96-frame number like pure text-only graphic scenes.

### Step 3 — play the voice in the scene

```tsx
import { Audio, staticFile } from 'remotion';

<Audio src={staticFile('audio/2026-06-LAUNCH_vo-S01_v1.mp3')} volume={1} />
```

### Step 4 — sync text overlays with the reading rhythm

If the scene has text overlays that appear with each sentence the voice speaks, split the text timing by audio markers (listen back to the voiceover, note each sentence's timestamp in `storyboard.md`); do not guess with a fixed interpolate.

## 3. Ducking — lowering background music under voiceover

When both background music and voiceover play together, the music must automatically lower its volume during the voice segments so it does not drown out the voice.

```tsx
const musicVolume = interpolate(
  frame,
  [voiceStartFrame - 15, voiceStartFrame, voiceEndFrame, voiceEndFrame + 15],
  [0.5, 0.15, 0.15, 0.5],
  { extrapolateLeft: 'clamp', extrapolateRight: 'clamp' }
);
```

`voiceStartFrame`/`voiceEndFrame` come from the position of the `<Sequence>` containing the voiceover in the Assembly.

## 4. Assembly — assembling multi-layer audio

```tsx
export const Assembly: React.FC = () => {
  return (
    <>
      <BackgroundMusic />
      <TransitionSeries>
        <TransitionSeries.Sequence durationInFrames={...}>
          <SceneWithVoice />  {/* this scene contains its own <Audio> voiceover inside */}
        </TransitionSeries.Sequence>
        {/* ... other scenes ... */}
      </TransitionSeries>
    </>
  );
};
```

`<BackgroundMusic />` sits outside the `TransitionSeries` (running in the background for the whole video). The voiceover sits INSIDE each corresponding scene component (playing only while that scene is on screen).

## 5. Pre-export checklist

- [ ] Listen to the whole video on external speakers (not just headphones) — check the background music/voice balance
- [ ] No clipping/distorted audio (volume > 1.0 from stacking multiple tracks)
- [ ] Voiceover is not cut off at the end of a sentence (check that `calculateMetadata` computed the duration correctly)
- [ ] Ducking works correctly — the music drops clearly when there is voice, not abruptly
- [ ] If a scene has original audio from an AI-VIDEO clip (`<OffthreadVideo>`) — check that it does not overlap with the background music at the same time and create a mess
