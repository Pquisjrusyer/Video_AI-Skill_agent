# Brand assets — Kolor Acrylic

> Folder hiện **trống**. File dưới đây do **người dùng cung cấp** (lấy từ brand / designer) — Claude KHÔNG tự vẽ, tự gen hay đoán logo, font, mã màu. Thiếu file nào thì `/edit` báo thiếu và dừng phần dùng file đó.

## File `/edit` (Remotion) cần

| Loại | File cần thả vào đây | Ghi chú |
|---|---|---|
| Logo | `logo-kolor.svg` (hoặc `.png` nền trong suốt), bản sáng + bản tối | Dùng cho end card / packshot |
| Font | File font (`.ttf`/`.otf`/`.woff2`) + tên font heading / body | Ghi vào bảng dưới |
| Palette | Mã hex màu brand | Ghi vào bảng dưới |

> Kolor chưa thấy badge chứng nhận bên thứ ba nào trên website. "Made in USA" là claim chữ, không có badge — nếu client có file badge chính thức thì thả vào đây.
